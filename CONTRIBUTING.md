# Contributing

Thanks for helping improve Female Anatomy Blast. Small, well-supported contributions are welcome.

## Anatomical corrections

Open an issue with the exact structure name or source ID, the observed problem, the proposed correction and a reliable anatomy reference. Describe the view and neighboring landmarks. A label fix, source geometry change and registration correction are different kinds of work; identify which one you mean.

Reference-based does not mean this assembly has been validated. Schematic parts must keep that designation until replaced with traceable reference geometry and reviewed placement. Do not remove limitations merely because all expected names are present.

## Geometry contributions

Provide creator, source URL, license, units, coordinate convention, side, relevant landmarks and any transformations or simplification. Use assets that permit redistribution and derivatives, including commercial reuse. Preserve attribution and share-alike requirements. Discuss a new asset license before mixing it into existing binary chunks. Do not submit identifiable scans or patient data.

Prefer a small reviewable change over replacing the entire body. Include front and side renders of the affected anatomy and describe what has and has not been checked.

## Code contributions

Fork the repository, create a branch and make a focused pull request. Run the checks listed in the README. The generated manifest and compressed geometry are runtime assets; if they change, regenerate the inventory audit and verify every concept references existing parts.

For UI work, cover search, selection, isolation, system visibility, touch interactions and narrow screens as appropriate. Keep source information accessible in the structure panel. No paid account is required for local development.

## Good starting points

- Review one schematic structure against an openly licensed anatomical reference.
- Improve a structure description with an authoritative citation.
- Add keyboard navigation or improve screen-reader descriptions.
- Document a reproducible source import and its exact transformations.
- Help verify alignment between female reference organs and shared adapted anatomy.

By contributing, you agree to license code under MIT and original model contributions under CC BY 4.0 unless an alternative compatible asset license is explicitly documented and accepted.
